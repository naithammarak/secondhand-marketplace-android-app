# คู่มือทดสอบ (QA) สำหรับเพื่อน — 2NDHAND APK

เป้าหมาย: ทดสอบแอปบนมือถือ Android จริง ให้ครบ 2 เส้นทางหลัก (ขายสำเร็จ / คืนเงิน) และหน้าสำคัญ แล้วบันทึกผล ผ่าน / ไม่ผ่าน พร้อมภาพหน้าจอ

ข้อเทคนิคที่ทดสอบด้วยมือไม่ได้ (Q05, Q12, Q13, Q15–Q19, Q25 เช่น race condition, worker อัตโนมัติ, migration) Lead/Claude ทดสอบด้วยระบบอัตโนมัติแยกต่างหาก

## ก่อนเริ่ม

1. ติดตั้ง APK จากลิงก์ที่ Lead ส่งให้ (ถ้ามือถือเตือน "ไม่รู้จักแหล่งที่มา" ให้กดอนุญาตติดตั้ง)
2. **ปลุกเซิร์ฟเวอร์ก่อนทุกครั้ง**: เปิด https://secondhand-api-gksn.onrender.com/health ในเบราว์เซอร์ รอจนขึ้น `{"status":"ok"}` (ครั้งแรกอาจรอ ~1 นาที เพราะเซิร์ฟเวอร์ฟรีหลับเมื่อไม่มีคนใช้)
3. เตรียมบัญชี Google 4 บัญชี และแจ้ง Lead ว่าบัญชีไหนเป็นบทบาทอะไร:
   - **ผู้ซื้อ (B)** — สมัครเองในแอป
   - **ผู้ขาย (S)** — สมัครในแอป แล้วขอเปิดร้านจากหน้าโปรไฟล์ ให้แอดมินอนุมัติ
   - **เจ้าหน้าที่ตรวจ (I)** และ **แอดมิน (A)** — สมัครในแอปก่อน แล้วให้ Lead ตั้งบทบาทให้ (แอปไม่มีปุ่มเลือกบทบาทเอง)
4. เงินทั้งหมดเป็น **เงินจำลอง** ไม่มีการตัดเงินจริง

## วิธีบันทึกผล

ทุกข้อให้กรอก: **ผ่าน / ไม่ผ่าน / ทำไม่ได้** + ภาพหน้าจอ ถ้าไม่ผ่านให้กรอกแบบฟอร์มแจ้งบั๊กท้ายเอกสาร

## C. เส้นทางที่ 1 — ขายสำเร็จ (Q04, Q06, Q07, Q08, Q10, Q22, Q23)

ใช้สินค้า ฿1,200 ของ S, ผู้ซื้อ B

| ข้อ | ใคร | ทำอะไร | ควรเห็น | ผล |
|---|---|---|---|---|
| C1 | B | ซื้อ → กรอกที่อยู่ → ชำระเงินจำลองสำเร็จ | ยอด 1,350 (สินค้า 1,200 + ส่ง 50 + ตรวจ 100), ได้ใบเสร็จ | |
| C2 | B | กดชำระซ้ำ/ย้อนกลับแล้วกดใหม่ | ไม่ถูกเก็บเงินซ้ำ ไม่มีคำสั่งซื้อซ้ำ | |
| C3 | S | ออเดอร์ร้าน → บันทึกที่อยู่รับคืน → แจ้งส่งเข้าศูนย์ (ใส่ชื่อขนส่งอะไรก็ได้ + เลขพัสดุ) | สถานะ "กำลังส่งเข้าศูนย์", ที่อยู่รับคืนแก้ไม่ได้แล้ว | |
| C4 | I | งานตรวจสินค้า → รับเข้าศูนย์ → เริ่มตรวจ → ถ่าย/เลือกรูปหลักฐาน → **แตะรูปเพื่อเลือก** → เลือก "ผ่าน" → พิมพ์สรุป → บันทึก | บันทึกผลได้ มีใบรับรอง + QR | |
| C5 | B | เปิดคำสั่งซื้อ → ดูผลตรวจ | เห็นใบรับรอง + เวลานับถอยหลัง 72 ชม. | |
| C6 | B | กด "ยอมรับผลการตรวจ" | สถานะรอศูนย์ส่งถึงคุณ | |
| C7 | I | บันทึกการส่งออก (ขนส่ง + เลขพัสดุ) **ไม่ต้องแนบรูป** | ส่งถึงผู้ซื้อ | |
| C8 | B | กด "ยืนยันว่าได้รับสินค้าแล้ว" | คำสั่งซื้อสำเร็จ | |
| C9 | S | ดูคำสั่งซื้อ | ได้รับ 1,140 (หักค่าคอม 60) เป็นยอดที่บันทึก | |
| C10 | B | ให้คะแนนผู้ขาย 1–5 ดาว + ความเห็น | บันทึกได้ครั้งเดียว | |
| C11 | ใครก็ได้ (ไม่ต้องล็อกอิน) | เปิดหน้าสินค้าของร้าน S → ดูรีวิว | เห็นคะแนน/รีวิว ไม่เห็นชื่อจริงผู้รีวิว | |
