## กติกาที่ต้องยึดทุกหน้า
- 1 ประกาศ = 1 ชิ้น, ไม่มีตะกร้า / รีวิว / wishlist / โค้ดส่วนลดใน API
- สภาพสินค้า 4 ค่าเท่านั้น สีตายตัว: `NEW` ใหม่ (เขียว) · `LIKE_NEW` เหมือนใหม่ (เขียวอมฟ้า) · `GOOD` ดี (ฟ้า) · `FAIR` พอใช้ (ส้ม)
- ยอดที่ผู้ซื้อจ่าย = ราคาสินค้า + ค่าส่ง ฿50 + ค่าตรวจสภาพ ฿100 · ผู้ขายได้รับ = ราคาสินค้า − ค่าธรรมเนียม 5%
- **ห้ามเปลี่ยนข้อความบนปุ่มที่มีอยู่แล้ว** เพราะเทสต์อัตโนมัติหาปุ่มจากข้อความ ถ้าจะเปลี่ยนต้องแจ้งหัวหน้า
- สีหลักเขียว Emerald, รองรับ dark/light
- โหลดรายการ/เนื้อหาใช้ skeleton
  - 💬 **ความเห็นจาก Mai:** ส่วนโหลดเอาเป็นอนิเมชันหมุนแบบรูปตัวอย่าง → ✅ ทำแล้ว: SVG ลูกศร 2 เส้น (เขียว/เข้ม) หมุนรอบกล่อง 1.2 วินาที/รอบ กล่องขยับขึ้นลงเบาๆ · ลูกศรล่าง+กล่องเปลี่ยนเป็นสีอ่อนในธีมมืด
  - **ใช้คู่กัน (ตกลงแล้ว):** skeleton = ตอนโหลดรายการ/การ์ด · ตัวหมุน = ตอนรอการกระทำ (รอการชำระเงินใน QR · ลากลงรีเฟรช · ปุ่ม "กำลังยกเลิก")
- ข้อมูลที่ API ยังไม่มี แต่อยากให้มี → ทำไว้ + ติดป้าย 🏷️ "ต้องเพิ่ม backend" + บันทึกในภาคผนวก B

## ภาคผนวก A — แนวคิดบทบาท ✅ ตกลงแล้ว (28 ก.ย.)
ทุกคนเริ่มเป็น **ผู้ซื้อ** · ขายได้เมื่อยืนยันตัวตนผู้ขาย **APPROVED** · ผู้ขายยังซื้อได้ · ไม่มีหน้าเลือกบทบาท

| สถานะผู้ใช้ | แท็บล่าง | ซื้อได้ | ขายได้ |
|---|---|---|---|
| Guest | 3 แท็บ | ต้องล็อกอินก่อน | – |
| ผู้ซื้อ (ยังไม่ยืนยัน / PENDING / REJECTED) | 3 แท็บ | ✅ | ❌ (การ์ดขอเปิดร้านในโปรไฟล์) |
| ผู้ขาย (APPROVED) | 5 แท็บ | ✅ ยกเว้นสินค้าตัวเอง | ✅ |

**Note สำหรับหัวหน้า:**
- โค้ดปัจจุบันยังใช้ role BUYER/SELLER เลือกครั้งเดียว และ backend ปฏิเสธการซื้อจากคนที่ไม่ใช่ BUYER (`buyer_role_required`) → ต้องให้ผู้ขายซื้อได้
- เงื่อนไข 5 แท็บ = verification ล่าสุด `APPROVED` → ให้ `/auth/me` ส่งสถานะนี้มาด้วย
- กันซื้อสินค้าของตัวเอง · หน้า "ออเดอร์ร้าน" ต้องมี API คำสั่งซื้อฝั่งผู้ขาย
- บัญชี ADMIN / INSPECTOR ต้องสั่งซื้อและลงขายไม่ได้ (backend ปฏิเสธ + mobile ซ่อนเมนูซื้อขาย) และใช้แท็บล่างชุดงานของตัวเอง
- **`POST /verifications` ต้องเปิดให้ผู้ซื้อส่งได้** (ตอนนี้ VERIFY-00 ให้เฉพาะ role SELLER) และเมื่อ APPROVED ต้องได้สิทธิ์ขายทันที
- จุดที่เกี่ยวข้อง: `services/me-service.ts`, `app/sell.tsx`, `components/marketplace-nav.tsx`, `api/orders.py`, `api/auth.py`, ตารางสิทธิ์ใน `VERIFY-00`
