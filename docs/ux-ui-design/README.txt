วิธีเปิดดู
--------------------------------------------------------------------------------
1. ดับเบิลคลิก "index.html" เปิดด้วย Chrome / Edge (แนะนำจอกว้าง ≥ 1024px)
2. เปิดแล้วจะเล่น Splash แล้วเข้าหน้าแรกแบบผู้เยี่ยมชม
3. ต่ออินเทอร์เน็ตเพื่อให้รูปสินค้าตัวอย่างและฟอนต์ขึ้น (ออฟไลน์ก็ใช้ได้ รูปจะเป็นไอคอนแทน)

แถบซ้าย (เครื่องมือดูต้นแบบ — ไม่ใช่ส่วนหนึ่งของแอป)
--------------------------------------------------------------------------------
ส่วนบน   : ธีมมืด/สว่าง · สถานะตอนนี้ (ใคร · บทบาท · หน้าไหน) · เปิด/ปิดป้าย "ต้องเพิ่ม backend" · รีเซ็ตต้นแบบ
🧭 Flow  : ไล่ดูตามเรื่อง กด "ถัดไป ›" ทีละขั้น (ทุกขั้นเริ่มจากข้อมูลตั้งต้น กดย้อน/ข้ามได้)
           1) ผู้ใช้ใหม่ซื้อชิ้นแรก            2) ผลตรวจผ่าน → ได้ของ → รีวิว
           3) ผลตรวจไม่ผ่าน → คืนเงิน/รับตามสภาพ  4) เปิดร้าน → ลงขาย → ได้เงิน
           5) ผู้ตรวจ: รับของ → ตรวจ → ส่งผล     6) แอดมิน: ดูแลความปลอดภัย
🗂️ หมวดหมู่: เปิดทีละหน้า/สถานะ มีช่องค้นหา
           เปิดแอป & เข้าสู่ระบบ · บทบาท & แท็บล่าง · ซื้อสินค้า · คำสั่งซื้อ · ขายของ
           ตรวจสอบ & ใบรับรอง · ปิดงาน/คืนเงิน/รีวิว · แจ้งเตือน · แอดมิน · โปรไฟล์ & ข้อมูลส่วนตัว
จอแคบ    : กด "☰ เมนูต้นแบบ" มุมซ้ายบน
