# ส่งต่องานให้หัวหน้า — ต้นแบบ UI 2NDHAND

> จัดทำโดย: Mai (Frontend / Mobile) · 29 ก.ย. 2026
> ต้นแบบ: `2NDHAND-mobile-prototype/index.html` (เปิดด้วย Chrome ได้เลย) · แผนละเอียดทีละหน้า: `UI-REDESIGN-PLAN.md`
> **วิธีดู:** แถบซ้ายแท็บ 🧭 **Flow** ไล่ดูทีละเรื่อง (ผู้ใช้ใหม่ซื้อ · ผลตรวจผ่าน/ไม่ผ่าน · เปิดร้าน · ผู้ตรวจ · แอดมิน) หรือแท็บ 🗂️ **หมวดหมู่** เปิดทีละหน้า/สถานะ
> ต้นแบบเป็น **ดีไซน์เท่านั้น** ไม่ได้แก้โค้ดใน `SAProject` · จุดที่ API ยังไม่มีจะติดป้ายเส้นประส้ม **"ต้องเพิ่ม backend"** (ปิดป้ายได้จากแถบซ้าย)

เอกสารนี้แบ่งเป็น 4 ส่วน
1. **เรื่องที่ต้องตัดสินใจ / ยืนยัน** — ต้นแบบเลือกทางไว้แล้ว แต่ต่างจากเอกสารหรือโค้ดเดิม
2. **งาน backend ที่ต้องเพิ่ม** — เรียงตามความสำคัญ (อ้างเลข B ในแผน)
3. **งานฝั่ง mobile ที่ไม่เกี่ยวกับ backend**
4. **เอกสารที่ควรแก้ให้ตรงกัน** (SRS / Sequence / Class Diagram)

## ส่วนที่ 2 — งาน backend ที่ต้องเพิ่ม

ลำดับความสำคัญ: **P1** = ขาดแล้ว flow หลักตาม SRS ไม่ครบ · **P2** = ฟีเจอร์ในขอบเขตแต่ไม่ใช่เส้นทางหลัก · **P3** = ทำไว้ให้ดูดีขึ้น ตัดได้

### P1 — flow หลัก (สั่งซื้อ → ตรวจ → ใบรับรอง → ปล่อยเงิน)

| # | เรื่อง | ต้องเพิ่ม | หน้าที่ใช้ |
|---|---|---|---|
