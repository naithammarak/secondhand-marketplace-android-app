3. เรื่องที่ต้องตัดสินใจก่อนไปต่อ

สี่ข้อนี้เปลี่ยนผลลัพธ์ของงานทั้งหมด จึงอยากได้คำตอบก่อนลงมือทำในโค้ดจริง

รับโครงหน้าแรกใหม่ไหม

ถ้ารับ ต้องแยกหน้าเข้าสู่ระบบออกจาก / และเพิ่มแถบแท็บ ซึ่งแตะไฟล์ของส่วน Auth ที่คนอื่นกำลังแก้อยู่ ควรเป็น task แยก

ชื่อแอปและโลโก้

ยังไม่มี ตัวอย่างนี้เว้นที่ไว้ให้แล้ว ถ้ายังไม่มีแผน ขอเสนอชื่อ 2-3 แบบให้เลือกได้

หมวดหมู่สินค้า

แถบหมวดหมู่ในหน้าแรกยังไม่มี API รองรับใน Contract v1.0 ถ้าจะมี ต้องเพิ่มงานฝั่ง backend

โหมดมืด

ในโค้ดเตรียมชุดสีมืดไว้แล้วแต่ยังใช้จริงไม่ได้ ถ้าต้องรองรับ จะเพิ่มงานทุกหน้า หน้านี้ทำสองโหมดไว้ให้ดูแล้ว

หน้านี้เป็นข้อเสนอรอบแรกเพื่อตัดสินทิศทาง ยังไม่ได้เขียนลงโค้ดจริง ข้อความและค่าต่าง ๆ อ้างอิงจาก SRS, Contract v1.0 และโค้ดใน mobile/src ณ วันที่ 24 ก.ย. 2026
