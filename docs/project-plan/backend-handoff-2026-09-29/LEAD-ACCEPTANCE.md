3. Capture request method/path, HTTP status, safe response fields, timestamp, role, order/product/inspection/shipment IDs and a correlation or test-run ID. Confirm persisted DB rows by an authorized read-only query on the test target after each write. For one-time/race invariants, use F3 PostgreSQL proof, not a phone tap alone.
