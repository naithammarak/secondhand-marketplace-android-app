# ทดสอบบนมือถือ: สั่งซื้อ จ่ายเงินจำลอง และยกเลิก (ORDER-04 / ORDER-05 / ORDER-06 / ORDER-08)

## เตรียม
- Backend ต่อฐานข้อมูล **ทดสอบ** ตั้ง `PAYMENT_SIMULATION_ENABLED=true` และ `APP_ENV` ไม่ใช่ production
- บัญชีทดสอบ 4 บัญชีตาม `backend/test-data/README.md`: Buyer A, Buyer B (BUYER), Seller เจ้าของสินค้า, Seller อื่น (SELLER)
- สินค้าของ Seller เจ้าของ: 1 ชิ้น `AVAILABLE`, 1 ชิ้น `RESERVED`, 1 ชิ้น soft-delete (จด product id ไว้)
- ภาพหลักฐานต้องปิดอีเมล ชื่อจริง เบอร์โทร และที่อยู่ก่อนแนบ

ทางเข้า: หน้าสินค้า → เปิดสินค้า → ปุ่ม **"ซื้อสินค้านี้"** (ทางหลัก)
ทางเข้าสำรองสำหรับทดสอบด้วยรหัสตรง ๆ: หน้าหลักหลัง Login → "ซื้อด้วยรหัสสินค้า (ทดสอบ)" และ "คำสั่งซื้อของฉัน"

> **ปุ่ม "ซื้อด้วยรหัสสินค้า (ทดสอบ)" ถูกปิดเป็นค่าตั้งต้น** (D-16) จะเห็นก็ต่อเมื่อเป็น build สำหรับพัฒนา
> และตั้ง `EXPO_PUBLIC_ORDER_DIRECT_ID_ENTRY=true` (โปรไฟล์ EAS `development` และ `mock` ตั้งไว้ให้แล้ว)
> build `preview`/`production` เปิดไม่ได้เลย ถ้าไม่เห็นปุ่มนี้ให้ใช้ทางหลักผ่านหน้าสินค้าแทน

**การทดสอบหมดเวลาจ่ายเงิน (M23–M25):** เส้นตายคือ 30 นาทีหลังสร้าง Order ถ้าไม่อยากรอจริง
ให้เลื่อนเส้นตายของ Order นั้นในฐานข้อมูล **ทดสอบ** ตรง ๆ แล้วกลับมากดในแอป:
```sql
UPDATE orders SET expires_at = now() - interval '1 minute' WHERE id = <order_id>;
```
ห้ามแก้ค่านี้บนฐานข้อมูลที่มีข้อมูลจริง

ยืนยันจำนวนจากฐานข้อมูลทดสอบหลัง M3–M6 (ไม่ใช่ดูจากหน้าจออย่างเดียว):
```sql
SELECT o.id, o.status,
  (SELECT count(*) FROM payment_attempts a WHERE a.order_id = o.id) AS attempts,
  (SELECT count(*) FROM payments p WHERE p.order_id = o.id) AS payments,
  (SELECT count(*) FROM escrows e WHERE e.order_id = o.id) AS escrows,
  (SELECT count(*) FROM receipts r WHERE r.order_id = o.id) AS receipts
FROM orders o ORDER BY o.id;
```
Expected ของ Order จาก M3: `WAITING_SELLER_SHIP, attempts=2, payments=1, escrows=1, receipts=1`

ตรวจการยกเลิกและการหมดเวลา (M21–M25) — Order ที่ยกเลิกต้องไม่มีแถวเงินเลย และสินค้าต้องกลับเป็น `AVAILABLE`:
```sql
SELECT o.id, o.status, o.cancel_reason, o.cancelled_at, o.paid_at, p.status AS product_status
FROM orders o JOIN products p ON p.id = o.product_id
WHERE o.status = 'CANCELLED';
```
Expected: `cancel_reason` เป็น `BUYER` (M21) หรือ `EXPIRED` (M23/M24), `paid_at` เป็น NULL เสมอ,
`product_status` เป็น `AVAILABLE` ยกเว้นเมื่อมีผู้ซื้อรายอื่นจองต่อไปแล้ว (M22/M25) จะเป็น `RESERVED`
