# Seller verification (ยืนยันตัวตนผู้ขาย)

ทางเข้า: หลัง Login ด้วยบัญชีที่มี role `SELLER` จะมีปุ่ม **ยืนยันตัวตนผู้ขาย** บนหน้าหลัก
(ปุ่มแสดงสถานะล่าสุดในวงเล็บ) กดแล้วเข้าหน้า `/seller-verification`

## สิ่งที่ต้องเตรียมก่อนทดสอบ

1. **Backend**
   - ตั้งค่า `.env` เพิ่มจาก `.env.example`
     - `SUPABASE_SERVICE_ROLE_KEY` — service role key ของโปรเจกต์ทดสอบ (อยู่ฝั่งเซิร์ฟเวอร์เท่านั้น
       ห้ามใส่ในแอปหรือ commit)
     - `SUPABASE_VERIFICATION_BUCKET` — ชื่อ bucket (ค่าเริ่มต้น `seller-verifications`)
   - สร้าง bucket แบบ **private** ชื่อเดียวกันใน Supabase Storage
   - รัน migration ล่าสุด: `alembic upgrade head` (เพิ่มดัชนีกันคำขอที่รอตรวจซ้ำ)
   - ถ้ายังไม่ตั้งค่า storage API จะตอบ 503 และแอปแสดงว่า "บริการยังไม่พร้อมใช้งาน"
2. **Mobile**
   - `expo-image-picker` เป็น native module ที่เพิ่งเพิ่มเข้ามา ต้อง **build dev client ใหม่**
     (`npx expo run:android` / `npx expo run:ios`) ก่อนทดสอบบนอุปกรณ์จริง
   - `EXPO_PUBLIC_API_BASE_URL` ต้องชี้ไปที่ backend ที่รันอยู่

## API ที่ใช้

| Method | Path | ผลลัพธ์ |
| --- | --- | --- |
| GET | `/verifications/me` | สถานะล่าสุดของผู้ขายคนที่ล็อกอิน (`NOT_SUBMITTED` เมื่อยังไม่เคยส่ง) |
| POST | `/verifications` | ส่งคำขอใหม่ (multipart: `bank_name`, `bank_account_name`, `bank_account_number`, `id_card_image`) |

รหัสตอบกลับที่แอปจัดการ: `401` ต่ออายุ session แล้วลองใหม่หนึ่งครั้ง, `403` ไม่ใช่ผู้ขาย,
`409` มีคำขอที่รอผลหรืออนุมัติแล้ว, `422` ข้อผิดพลาดรายช่อง (`detail.fields`), `503` ยังไม่พร้อมใช้งาน
API ไม่ส่ง URL ของรูปบัตรประชาชนกลับมาที่เครื่องผู้ใช้ และส่งเลขบัญชีกลับเฉพาะ 4 ตัวท้าย

## สิ่งที่ต้องตรวจด้วยมือ

- **ส่งคำขอจริง:** กรอกครบ แนบรูป กดส่ง → สถานะเปลี่ยนเป็น "รอตรวจสอบ" และฟอร์มถูกล้าง
- **ข้อผิดพลาดรายช่อง:** เว้นว่างหรือกรอกเลขบัญชีสั้นกว่า 10 หลัก → ข้อความสีแดงขึ้นใต้ช่องนั้น ๆ
  และยังไม่ยิง API
- **กันกดส่งซ้ำ:** ระหว่างรอผล ฟอร์มจะถูกซ่อนและกดส่งซ้ำไม่ได้ กดปุ่มรัวระหว่างส่งยิง API ครั้งเดียว
- **ถูกปฏิเสธ:** ให้ผู้ตรวจตั้ง `verification_status='REJECTED'` พร้อม `reject_reason` ในฐานข้อมูล →
  แอปแสดงเหตุผล และเปิดฟอร์มให้ส่งคำขอใหม่
- **ปิดเปิดแอปใหม่:** สถานะที่เห็นต้องตรงกับ backend เสมอ (แอปไม่ได้เก็บสถานะไว้ในเครื่อง)
- **เครือข่ายผิดพลาด:** ปิดเน็ตแล้วเข้าหน้านี้ → เห็นข้อความผิดพลาดพร้อมปุ่ม "ลองใหม่อีกครั้ง"
  เปิดเน็ตแล้วกดลองใหม่ต้องโหลดสำเร็จ
- **เปลี่ยนบัญชี / Logout:** ออกจากระบบแล้วเข้าด้วยบัญชีผู้ขายอีกคน ต้องไม่เห็นข้อมูลของบัญชีก่อนหน้า
  แม้ชั่วขณะระหว่างโหลด
